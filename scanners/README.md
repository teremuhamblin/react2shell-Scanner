# Dossier scanners/
Module de scans avancés pour la détection, l’analyse et la surveillance des vulnérabilités liées à React2Shell (CVE‑2025‑55182) et autres comportements suspects.

## Contenu des scripts

- **scanner.js** — Scanner principal militaire renforcé  
- **net_probe.js** — Analyse réseau (ports, latence, anomalies)  
- **flight_analyzer.js** — Analyse profonde des payloads Flight  
- **proto_detector.js** — Détection de prototype pollution  
- **server_fingerprint.js** — Fingerprinting du serveur (Next.js / Node.js)  
- **monitor.js** — Monitoring tactique du serveur (CPU, RAM, processus)

## Objectifs

- Détecter les comportements suspects liés à React2Shell  
- Identifier les anomalies réseau et applicatives  
- Surveiller les processus et la charge système  
- Renforcer la sécurité du projet SiteWebPerso‑Security  
- Offrir une base militaire de détection avancée
