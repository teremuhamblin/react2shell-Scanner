# 📄 React2Shell
### overview.md

Vue d’ensemble

React2Shell est une vulnérabilité critique affectant React Server Components et Next.js, permettant une exécution de code à distance via un payload Flight malformé.

Points clés

- RCE pré‑authentifiée  
- Exploitation simple  
- Impact massif  
- Campagnes actives depuis 2025  

Architecture simplifiée

`
Client → Flight → Serveur RSC → Désérialisation → RCE
`
